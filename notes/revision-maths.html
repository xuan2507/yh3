Mathematics 9709 - Last Minute Revision

Condensed essentials for exam day. For full notes, click "Full Notes" above.

Must-Know Formulas

Quadratics

x = [-b +/- sqrt(b^2 - 4ac)] / 2a
Discriminant = b^2 - 4ac

Binomial

(1+x)^n = 1 + nx + n(n-1)x^2/2! + ... (|x|<1)

Trigonometry

sin^2(x) + cos^2(x) = 1
1 + tan^2(x) = sec^2(x)
sin(2x) = 2sin(x)cos(x)
cos(2x) = cos^2(x) - sin^2(x) = 2cos^2(x) - 1 = 1 - 2sin^2(x)

Differentiation

d(x^n)/dx = nx^(n-1)
d(e^x)/dx = e^x
d(ln x)/dx = 1/x
d(sin x)/dx = cos x
d(cos x)/dx = -sin x
Chain: dy/dx = dy/du * du/dx
Product: d(uv)/dx = u(dv/dx) + v(du/dx)
Quotient: d(u/v)/dx = [v(du/dx) - u(dv/dx)]/v^2

Integration

integral x^n dx = x^(n+1)/(n+1) + c (n != -1)
integral 1/x dx = ln|x| + c
integral e^x dx = e^x + c
integral sin x dx = -cos x + c
integral cos x dx = sin x + c
By parts: integral u dv = uv - integral v du

Series

AP: nth term = a + (n-1)d, Sn = n/2[2a + (n-1)d]
GP: nth term = ar^(n-1), Sn = a(1-r^n)/(1-r), S_inf = a/(1-r) for |r|<1

Coordinate Geometry

Distance = sqrt[(x2-x1)^2 + (y2-y1)^2]
Midpoint = [(x1+x2)/2, (y1+y2)/2]
Gradient = (y2-y1)/(x2-x1)
Perpendicular: m1 * m2 = -1
Circle: (x-a)^2 + (y-b)^2 = r^2

Algebra - Quick Tips

Completing the square: x^2 + bx + c = (x + b/2)^2 - (b/2)^2 + c

Polynomial division: If f(a) = 0, then (x-a) is a factor.

Partial fractions: Linear -> A/(x-a) + B/(x-b). Repeated -> add C/(x-a)^2. Quadratic -> (Ax+B)/(quadratic)

Log laws: log(ab) = log a + log b, log(a/b) = log a - log b, log(a^n) = n log a

Change base: log_b(a) = log(a)/log(b)

Calculus

Stationary points: dy/dx = 0

  • Max: d^2y/dx^2 < 0
  • Min: d^2y/dx^2 > 0
  • Point of inflection: d^2y/dx^2 = 0 AND changes sign

Increasing: dy/dx > 0. Decreasing: dy/dx < 0

Area: integral from a to b of y dx. If curve below axis, area = |integral|

Volume: pi * integral of y^2 dx

Parametric: dy/dx = (dy/dt)/(dx/dt)

Implicit: Differentiate y terms and multiply by dy/dx

Series

AP: a, a+d, a+2d... Add common difference.

GP: a, ar, ar^2... Multiply by common ratio.

Sum to infinity: Only when |r| < 1. Formula: a/(1-r)

Binomial valid: |x| < 1 for (1+x)^n where n is negative/fractional

P3 Quick Topics

Vectors:

  • |ai+bj+ck| = sqrt(a^2+b^2+c^2)
  • a.b = |a||b|cos(theta) = a1b1+a2b2+a3b3
  • Line: r = a + tb
  • Plane: r.n = d or ax+by+cz=d

Differential equations: Separate variables then integrate both sides.

Complex numbers:

  • z = x + iy = r(cos theta + i sin theta)
  • |z| = r = sqrt(x^2+y^2)
  • arg(z) = theta = arctan(y/x)
  • De Moivre: [r(cis theta)]^n = r^n cis(n theta)
  • Multiply: multiply moduli, add arguments

Exam Tips: Show ALL working. Check answers by substitution. Watch for exact value questions. Sketch graphs when asked. For integration, don't forget +c (indefinite). In trig, check if answer should be in degrees or radians.
