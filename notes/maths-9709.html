Pure Mathematics 1 (P1)

Quadratics & Functions

Completing the Square

ax^2 + bx + c = a(x + b/2a)^2 - (b^2/4a) + c

Useful for: finding vertex, solving equations, sketching curves

Example: x^2 + 6x + 5 = (x + 3)^2 - 9 + 5 = (x + 3)^2 - 4

Vertex at (-3, -4)

Quadratic Formula

x = [-b +/- sqrt(b^2 - 4ac)] / 2a

Discriminant (b^2 - 4ac)

Functions

  • Domain: Set of input values
  • Range: Set of output values
  • One-one function: Each output from exactly one input (passes horizontal line test)
  • Inverse function f^-1: Swap x and y, solve for y
  • Composite function fg(x): g first, then f. So fg(x) = f(g(x))

Coordinate Geometry

Key Formulas

Distance: d = sqrt[(x2-x1)^2 + (y2-y1)^2]
Midpoint: [(x1+x2)/2, (y1+y2)/2]
Gradient: m = (y2-y1)/(x2-x1)
Equation of line: y - y1 = m(x - x1)
Perpendicular gradient: m1 * m2 = -1

Circle Equations

Centre (a,b), radius r: (x-a)^2 + (y-b)^2 = r^2
General form: x^2 + y^2 + 2gx + 2fy + c = 0

Centre = (-g, -f), Radius = sqrt(g^2 + f^2 - c)

Circular Measure

Radians

1 radian = 180/pi degrees
pi rad = 180 degrees

Arc Length & Sector Area

Arc length: s = r * theta (theta in radians)
Sector area: A = (1/2) * r^2 * theta
Segment area: A = (1/2) * r^2 * (theta - sin(theta))

Series

Binomial Expansion

(1 + x)^n = 1 + nx + [n(n-1)/2!]x^2 + [n(n-1)(n-2)/3!]x^3 + ...

Valid for |x| < 1 and n is negative or fractional.

For (a + bx)^n, factor out a^n first: a^n(1 + bx/a)^n

Arithmetic Progression (AP)

nth term: a + (n-1)d
Sum of n terms: S_n = n/2 [2a + (n-1)d] = n/2(a + l)

Geometric Progression (GP)

nth term: ar^(n-1)
Sum of n terms: S_n = a(1-r^n)/(1-r) or a(r^n-1)/(r-1)
Sum to infinity: S = a/(1-r) for |r| < 1

Rules

Product rule: d(uv)/dx = u(dv/dx) + v(du/dx)
Quotient rule: d(u/v)/dx = [v(du/dx) - u(dv/dx)] / v^2
Chain rule: dy/dx = dy/du * du/dx

Applications

  • Increasing function: dy/dx > 0
  • Decreasing function: dy/dx < 0
  • Stationary points: dy/dx = 0
  • Maximum: dy/dx = 0, d^2y/dx^2 < 0
  • Minimum: dy/dx = 0, d^2y/dx^2 > 0
  • Point of inflection: d^2y/dx^2 = 0 (and changes sign)

Pure Mathematics 3 (P3)

Algebra

Polynomial Division

Factor theorem: If f(a) = 0, then (x-a) is a factor.

Remainder theorem: f(a) = remainder when f(x) divided by (x-a).

Partial Fractions

Linear factors: (3x+5)/[(x-1)(x+2)] = A/(x-1) + B/(x+2)

Repeated factor: Add B/(x-a)^2 term

Irreducible quadratic: (Ax+B)/(quadratic)

Logarithmic & Exponential Functions

Laws of Logarithms

log(a) + log(b) = log(ab)
log(a) - log(b) = log(a/b)
n*log(a) = log(a^n)
log(a)/log(b) = log_b(a) (change of base)

Solving Exponential Equations

2^x = 5 => x = log(5)/log(2) = ln(5)/ln(2)

5^(2x) - 5^x - 6 = 0. Let y = 5^x: y^2 - y - 6 = 0

Trigonometry (P3)

Compound Angle Formulas

sin(A+B) = sinAcosB + cosAsinB
sin(A-B) = sinAcosB - cosAsinB
cos(A+B) = cosAcosB - sinAsinB
cos(A-B) = cosAcosB + sinAsinB
tan(A+B) = (tanA + tanB)/(1 - tanAtanB)

Double Angle Formulas

sin(2A) = 2sinAcosA
cos(2A) = cos^2A - sin^2A = 2cos^2A - 1 = 1 - 2sin^2A
tan(2A) = 2tanA/(1 - tan^2A)

R-Formula (a cos(x) + b sin(x))

a cos(x) + b sin(x) = R cos(x - alpha)

where R = sqrt(a^2 + b^2), tan(alpha) = b/a

OR: R sin(x + alpha) where tan(alpha) = a/b

Differentiation (P3)

Implicit Differentiation

Differentiate both sides with respect to x.

For y terms: d(y^2)/dx = 2y(dy/dx)

Parametric Differentiation

dy/dx = (dy/dt)/(dx/dt)

Integration (P3)

Advanced Techniques

Integration by parts: integral u dv = uv - integral v du

LIATE rule for choosing u: Log, Inverse trig, Algebraic, Trig, Exponential

Substitution: Change variable to simplify integral

Differential Equations

Variables Separable

dy/dx = f(x)g(y) => integral (1/g(y)) dy = integral f(x) dx

Use initial conditions to find constant of integration.

Vectors

Key Formulas

Magnitude: |ai + bj + ck| = sqrt(a^2 + b^2 + c^2)
Dot product: a.b = |a||b|cos(theta) = a1b1 + a2b2 + a3b3
Angle: cos(theta) = (a.b)/(|a||b|)
Line: r = a + tb (point a, direction b, parameter t)

Plane Equation

r.n = d where n is normal vector
ax + by + cz = d

Complex Numbers

Forms

Cartesian: z = x + iy
Polar: z = r(cos(theta) + i sin(theta)) = r * e^(i*theta)
Modulus: |z| = r = sqrt(x^2 + y^2)
Argument: arg(z) = theta = arctan(y/x)

Operations

Multiply: multiply moduli, add arguments
Divide: divide moduli, subtract arguments
De Moivre's: [r(cos(theta) + i sin(theta))]^n = r^n(cos(n*theta) + i sin(n*theta))
